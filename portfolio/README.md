## Initiative catalog requirements

Maintain stable initiative IDs, objectives, rationale, participating repository references, scope boundaries, maturity, dependencies, success criteria, next actions, evidence and review dates. Public records must be explicitly approved for disclosure. Internal commercial strategy and private repository inventory belong in access-controlled organizational records.

Initial public technical themes for review: secure construction, reproducible verification, capability-based interoperability, unified design, structured knowledge, and automated evidence generation. These are planning themes, not claims of implementation.

## Maintenance

Agents should consult the portfolio before proposing new systems. Reconcile with canonical manifests, identify overlap and stale entries, and preserve optional-provider independence. Never modify generated distribution channels or declare new provided capabilities merely to record a planning initiative. Verify descriptions against repository documentation before marking them authoritative. Keep confidential information out of public records.
